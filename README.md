# Página Web de Deportes - INFODEPORTE
He subido el proyecto de mi página web de deportes, llamada INFODEPORTE, creada con React. Esta plataforma está diseñada para proporcionar contenido actualizado sobre el mundo deportivo, incluyendo noticias, análisis, resultados en vivo y otros recursos relevantes para los fanáticos del deporte.

La web está pensada para ser dinámica e interactiva, con una interfaz limpia y moderna, optimizada para ser visualizada tanto en dispositivos de escritorio como móviles.



# Características del proyecto:
Texto descriptivo: Una breve recapitulación sobre el mundial de fútbol 2022, incluyendo el rendimiento de los equipos y momentos clave del torneo.

Imagen: Una foto representativa de la final entre Argentina y Francia, capturando la esencia de ese increíble partido.

Video: Un video que muestra la famosa tanda de penales entre Argentina y Francia, con los momentos más emocionantes de ese desenlace.
